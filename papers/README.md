# Shared PDFs used by chatbot prompts

Place open-access companion PDFs here so the Methods Consultant specification can cite stable local paths alongside DOIs.

## Rosenberg & Anderson (2010) — *Statistics in Medicine*

- **Citation:** Rosenberg PS, Anderson WF. Proportional hazards models and age-period-cohort analysis of cancer rates. *Stat Med.* 2010;29(11):1228–1238. DOI https://doi.org/10.1002/sim.3865
- **Suggested filename in this repo:** `Rosenberg_Anderson_2010_SIM_APC.pdf`

The NIH manuscript (PMC [PMC2904510](https://pmc.ncbi.nlm.nih.gov/articles/PMC2904510/), PMID [20209480](https://pubmed.ncbi.nlm.nih.gov/20209480/)) is openly available.

**Downloading the PDF:** open the [PMC article page](https://pmc.ncbi.nlm.nih.gov/articles/PMC2904510/), use the sidebar **PDF** link (typically ~865 KB), and save the file into this folder using the suggested filename above. The publisher site resolves the DOI `10.1002/sim.3865` to Wiley; the PMC copy avoids paywall tooling for this repository setup.
